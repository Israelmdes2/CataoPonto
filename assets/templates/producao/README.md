# Templates Visuais - Ambiente de Produção

Armazene nesta pasta os prints/templates PNG recortados da tela do Senior no ambiente de **Produção**.

### Principais templates necessários:
- `botao_autenticar.png`: Botão 'Autenticar' da tela de login do Senior em produção.
- `campo_login.png`: Ícone / texto do campo de Usuário.
- `campo_senha.png`: Ícone / texto do campo de Senha.
- Demais menus e botões específicos que diferem de homologação.

> O sistema buscará primeiro nesta pasta (`assets/templates/producao/`). Se um template específico não for encontrado aqui, o robô automaticamente faz fallback para o template padrão em `assets/templates/`.
